A tiny deterministic program that writes one original word to `entry.txt`: the first word that comes to mind — "Murmuration", a flock of starlings wheeling as one dark ribbon across a dusk sky, and also a soft murmuring sound. Surprising, vivid, and carrying a spark of wit in its own mur-mur sound. The word is 11 characters, and the program is stdlib-only with no network, clock, or randomness.

## Run it

```sh
python3 main.py
```
